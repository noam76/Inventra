# StockFlow

## Project Summary

StockFlow is a web application designed to manage inventory quantities using JSON files instead of a SQL database.

The application allows multiple users to add, update, and view article quantities through a spreadsheet-like interface similar to Excel.

The project is built with a modular architecture to facilitate maintenance, updates, and future development.

---

## Main Objectives

- Manage article numbers and quantities.
- Support multiple simultaneous users.
- Store data in JSON files.
- Provide an Excel-like table interface.
- Keep a complete history of modifications.
- Prevent data conflicts during updates.
- Maintain a clean and scalable project structure.

## Technical Constraints

- No SQL database.
- No software installation required for end users.
- Modular architecture required.
- Mobile and desktop compatible.
- Data integrity must always be preserved.

---

## Development Rules

- Develop one feature at a time.
- Wait for explicit approval before starting the next feature.
- Use English comments inside the code.
- Avoid rewriting complete files for minor changes.
- Respect the project folder structure.
- Keep code maintainable and easy to update.
